# BudgetApp
SmartBudgeter is a modern, online budgeting application designed to help you track and manage your finances effortlessly. With a sleek frontend built in React and Tailwind CSS, and a backend powered by Supabase, this app gives you an intuitive way to visualise spending, set budgets, and gain insights, all hosted on Netlify.
